# 📊 Универсальный шаблон Python-окружения для анализа данных

Готовая и проверенная заготовка для быстрого старта аналитических проектов. Включает в себя актуальные версии библиотек, преднастроенный интерактивный блокнот и пошаговые инструкции.

## 🗂 Структура шаблона
* **`requirements.txt`** — список зафиксированных и актуальных версий библиотек (включая NumPy 2.x, Pandas 2.x, Seaborn и Matplotlib).
* **`project.ipynb`** — интерактивный Jupyter-ноутбук с готовым базовым кодом для проверки визуализации и импорта данных.
* **`TODO.md`** — пошаговый интерактивный чек-лист для развертывания виртуального окружения в Windows.
* **`GITHUB.md`** — шпаргалка со всеми командами для публикации этого проекта в новый репозиторий.

## 🚀 Быстрый старт (Windows)
1. Склонируйте или скачайте этот репозиторий.
2. Откройте папку в **VS Code**.
3. Откройте встроенный терминал (`Ctrl + \``) и запустите создание окружения:
   ```bash
   python -m venv .venv
   ```
4. Активируйте его:
   ```bash
   .venv\Scripts\Activate.ps1
   ```
5. Установите все зависимости:
   ```bash
   pip install -r requirements.txt
   ```
6. Откройте файл `project.ipynb`, выберите ядро `.venv` в правом верхнем углу и запустите ячейку для проверки!
